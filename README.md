# Portfolio de Alex Ortega Redondo

Portfolio personal desarrollado con **Vite + React + TypeScript + Tailwind CSS**.

La web presenta mi perfil como estudiante de Ingeniería Informática, con foco en **datos, machine learning, desarrollo de software y aplicaciones web**. Incluye proyectos propios, experiencia profesional, formación y vías de contacto.

## Características

- Interfaz responsive para móvil, tablet y escritorio.
- Portada con presentación, foto, enlaces profesionales y descarga del CV.
- Sección de stack técnico organizada por categorías.
- Proyectos destacados con demos en vídeo y enlaces a repositorios.
- Sección de experiencia y formación.
- Contacto mediante email, LinkedIn y GitHub.

## Tecnologías utilizadas

- Vite
- React
- TypeScript
- Tailwind CSS
